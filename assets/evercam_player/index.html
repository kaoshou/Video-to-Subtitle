    操作說明與鍵盤快捷鍵
    快速定位與基本操作

    按 Tab 移至下一個連結或控制項，Shift + Tab 回到上一項；焦點所在位置會有外框。按 Enter 啟用連結；按鈕可用 Enter 或 Space。

    定位連結平時隱藏，從頁面第一個 Tab 停留點可依序選取，取得鍵盤焦點時才會顯示；按 Enter 跳至對應區域。也可直接使用下列瀏覽器定位快捷鍵，會自動切換分頁或展開逐字稿，再按 Tab 即可操作內容。

    Windows 的 Chrome／Edge：Alt + 代碼；Firefox：Alt + Shift + 代碼。macOS 的 Chrome／Safari／Firefox：Control + Option + 代碼。例如 Windows Chrome 用 Alt + T 定位逐字稿。若組合鍵由瀏覽器或輔助工具使用，可改用 Tab 選取定位連結。

    一般 MP4 或沒有章節的課程不提供章節定位快捷鍵。沒有字幕時，逐字稿會顯示提示，相關搜尋與下載功能停用。

    播放、音量與全螢幕

    先用定位快捷鍵或 Tab 選取「跳至播放器」，也可直接點影片畫面，讓焦點進入播放器。點影片可播放／暫停；下列按鍵的生效位置各有不同。

    播放快捷鍵與生效位置
    按鍵功能與生效位置
    Space影片畫面取得焦點時播放／暫停；焦點在按鈕上時，執行該按鈕功能。
    ← / →影片畫面取得焦點時快退／快轉 10 秒。
    M影片畫面或一般控制按鈕取得焦點時，切換靜音。
    F影片畫面或一般控制按鈕取得焦點時，切換全螢幕。
    Esc關閉播放器選單或閱讀設定並返回開啟按鈕；在全螢幕時離開全螢幕。於本說明區可收合說明。

    搜尋欄、下拉選單、滑桿及字幕設定內保留原本的鍵盤操作，不觸發上述播放快捷鍵。在頁面其他區域按 M 或 F 不會控制影片。

    進度與音量滑桿：用 Tab 移入後，以方向鍵增減、Home／End 移至最小／最大值；時間及音量百分比會提供給輔助工具。窄螢幕未顯示音量滑桿時，可使用裝置音量鍵。子母畫面按鈕只在瀏覽器支援時顯示。

    字幕、速度與選單

    在 CC 或播放速度按鈕按 Enter、Space 或 ↓ 開啟選單。播放速度清單以 ↑／↓ 移動、Home／End 選到第一／最後一項，Enter 或 Space 套用；套用後回到開啟按鈕。

    CC 字幕設定使用 Tab／Shift + Tab 巡覽，Enter 或 Space 選擇字幕語言、關閉字幕或進入「字幕外觀」。字級、底色與位置可在字幕外觀內調整。Esc 關閉並返回 CC 按鈕；Tab 也可離開選單。

    章節、逐字稿與閱讀設定

    EverCam 的「章節／逐字稿」分頁以 ←／→ 切換，Home／End 移至第一／最後分頁；按 Tab 進入分頁內容。章節按鈕以 Enter 或 Space 跳到對應時間。一般 MP4 不顯示章節分頁，直接提供逐字稿。

    逐字稿先選語言，輸入關鍵字可即時搜尋；「清除」還原全部內容。逐字稿段落以 Enter 或 Space 跳到對應時間並播放；「顯示更多／顯示前段」可瀏覽其他段落。

    「跟隨播放」預設關閉，按 Space 勾選後，自動捲動到播放中的字幕；搜尋期間暫停跟隨。跟隨不會搶走鍵盤焦點。

    在「閱讀設定」按 Enter 或 Space 展開，以 Tab 巡覽字級、行距、高對比及下載選項；下拉選單用方向鍵選擇。Esc 收合並回到「閱讀設定」；Tab 可直接離開。下載閱讀版 HTML 或 TXT 會包含所選語言的全部逐字稿，亦可勾選時間標記。
