# MCP 工作流程增強

## 已確認範圍

使用者選定開始前確認、真實進度、中斷後接續、翻譯品質檢查、完整結果摘要五項。2026-11-05 確認：設定明確就直接執行，缺漏、模型不可用或需要變更方案時才詢問，不增加每次必答的確認視窗。

## 方案與邊界

採現有 MCP 服務、私人狀態與桌面工作卡片漸進擴充；不另建工作流引擎，也不自動串接另一家 AI 服務。另建引擎會重複既有排程、授權與冪等機制，增加相容風險。沿用 Python／CustomTkinter，不增加依賴。

- 預檢提供影片、實際解析設定、模型就緒狀態、批次策略、輸出位置與阻擋原因；唯讀，不下載、刪除或載入模型。預檢不保證後續檔案或硬體狀態未變，執行時仍重驗。
- 工作進度以引擎或複製回呼為準，按階段標示；未知進度使用 null，不產生虛構百分比。記錄實際開始／結束與耗時，排隊時間不當作轉錄耗時。
- 使用者換對話後，可依影音找回已完成來源、各語言翻譯草稿與缺少批次。保留授權、來源版本與 request_id 冪等；已中止語音轉錄必須明確重新執行，不承諾解碼中途續跑。
- 翻譯品質檢查：既有結構錯誤（漏 cue、空白、修改時間軸）繼續拒絕；異常長句、疑似未翻譯與可驗證的術語不一致列為提醒，不擅改內容，也不宣稱語意翻譯正確。可用明確結構的術語對照，保留現有自由文字 glossary。
- 完成摘要回報實際模型／引擎／設備、耗時、語言、段數、校對原因與結果位置。原字幕模型與外部翻譯服務分開，不猜測外部模型。

保留一般模式與受限模式、符號連結防護、不可覆寫原檔、來源時間軸、舊紀錄可讀性及現有工具輸入相容性。查詢皆有分頁或數量／回應大小上限；不預設掃描使用者所有目錄。

## 驗收

以合成資料驗證模型缺少、取消、來源改變、翻譯重送與接續、過長譯文、舊工作紀錄及三種播放器匯出。桌面測試確認狀態卡片可讀、取消與開啟結果可用。此範圍不包含推送、版本提升、Windows 封裝或 Release。
