# 2.9.1 播放器與匯入修正

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成使用者指定的 MP4 預設逐字稿、專案徽章、資料夾判斷與 2.9.1 成品命名。

**Architecture:** 沿用 EverCam 共用 JS/CSS 與無障礙控制；一般 MP4 只省略章節，直接顯示逐字稿。主清單先依實際檔案型態分流，專案辨識沿用原檢測器。發布前三個成品由獨立標準庫腳本整理命名，網站漸進式解析最新 Release 資產。

**Tech Stack:** Python、CustomTkinter、JavaScript、Node test、Playwright、GitHub Actions。

**Spec:** 本計畫中的「使用者要求與邊界」。

## 使用者要求與邊界

- 一般 MP4 右側直接顯示逐字稿；EverCam 預設章節不變。搜尋、跟隨、閱讀設定、下載、鍵盤操作維持共用。
- 待處理清單每列依實際專案顯示 EverCam 或 OpenCam 徽章；一般影片不顯示。
- 名為 `示範課程.ecmx.mp4` 的資料夾仍是資料夾，須找內部實際影音；不能交給轉錄器當影片。
- 版本為 2.9.1。不清除模型，不變更安全輸出防護。
- 成品僅三個：`VideoToSubtitle_v2.9.1_macOS_arm64.dmg`、`VideoToSubtitle_v2.9.1_Windows_x64_Portable.zip`、`VideoToSubtitle_v2.9.1_Windows_x64_Setup.exe`。
- ZIP 內維持可直接執行的獨立 `VideoToSubtitle.exe`；不要求 Python。
- 網站不寫死版本下載網址；解析最新正式 Release，失敗時保留 latest 頁面入口。README 同樣連最新 Release。
- 本次只本機修改、測試與準備發布流程；未明確要求推送或刪除歷史成品，不操作既有 Release。
