# Video to Subtitle 完整使用手冊（繁體中文）

> 影音內容只在本機處理，不會上傳至雲端。首次下載語音模型，以及啟動時自動或手動檢查 GitHub 更新時需要網路；這些連線只取得模型或版本資訊。自動產生的字幕仍應由人工核對。

Video to Subtitle 是以 faster-whisper（Windows／一般 CPU 與 CUDA）及 mlx-whisper（macOS Apple Silicon）為核心的桌面工具，可將影音轉成 SRT、VTT、TXT、TSV 或 JSON，並在同一套程式內完成字幕校對與影音同步預覽。

## 下載與系統需求

請只從 [GitHub Releases](https://github.com/kaoshou/Video-to-Subtitle/releases/latest) 下載最新版。Windows 可選 `VideoToSubtitle-Setup-v<版本>.exe` 安裝版或 `VideoToSubtitle.exe` 免安裝版；macOS 發行檔為 `VideoToSubtitle.dmg`。

第一次使用某個 Whisper 模型時需要網路連線。模型下載完成後，一般轉錄、字幕校對及 EverCam 轉換均可在本機執行。模型需要約 75 MB 至 3.1 GB，請預留比模型標示大小更多的暫存與解壓縮空間。

### Windows 安裝與啟動

1. 下載最新的 `VideoToSubtitle.exe`。
2. 將檔案放在有寫入權限的位置，例如自己的文件資料夾。
3. 雙擊執行。若 Windows SmartScreen 顯示保護提示，先確認檔案確實來自本專案的官方 Releases，再依系統畫面選擇顯示詳細資訊並執行。
4. 使用 CPU 不需要額外設定；CUDA 為具備相容 NVIDIA 顯示卡之使用者的選用加速功能。

#### Windows 安裝版（自 v2.7.14 起）

正式 Release 另提供 `VideoToSubtitle-Setup-v<版本>.exe` 安裝版（本次為 `VideoToSubtitle-Setup-v2.8.0.exe`）。免安裝的 `VideoToSubtitle.exe` 繼續保留。

1. 從[官方 Releases](https://github.com/kaoshou/Video-to-Subtitle/releases/latest) 下載 **VideoToSubtitle-Setup** 安裝包，依繁體中文精靈安裝。預設僅供目前使用者使用，不要求系統管理員權限；可改安裝位置、選擇是否建立桌面捷徑。
2. 從「開始」功能表的 **Video to Subtitle** 啟動，或使用已選擇建立的桌面捷徑。安裝包已內含 Python 與必要套件，不需事先準備執行環境。
3. 初次使用語音模型仍需下載；安裝版不另外附贈模型。CPU 可直接使用，CUDA 仍需相容 NVIDIA 顯示卡與驅動。
4. 更新前關閉程式，再執行新安裝包。解除安裝可在 Windows「已安裝的應用程式」找到 **Video to Subtitle**；它不會刪除使用者設定、模型或影音。

預設程式安裝在 `%LOCALAPPDATA%\Programs\VideoToSubtitle`；Windows 封裝版的設定另存 `%LOCALAPPDATA%\VideoToSubtitle\config.json`，安裝版與新版免安裝版共用。模型仍在 `~/.cache/huggingface/hub` 或您指定的模型目錄。原始碼／macOS 的設定位置不變。

安裝版使用資料夾式封裝，執行環境只在安裝時解壓，可減少每次啟動的等待；不改變模型計算速度。首次啟動、重複啟動以及防毒掃描都可能影響體感，請以實際電腦測試為準，不需關閉防毒。目標平台為 Windows 10／11 x64，Windows ARM 不在此次驗證範圍。

### macOS 安裝與啟動

1. 下載最新的 `VideoToSubtitle.dmg`。
2. 開啟 DMG，將 VideoToSubtitle 拖入「應用程式」。
3. 第一次啟動若被 macOS 阻擋，請先確認 DMG 來自官方 Releases，再於 Finder 對程式按住 Control 點按並選擇「打開」，或依「隱私權與安全性」畫面的提示允許開啟。
4. Apple Silicon Mac 可在「運算單元」選擇 `mlx`；若 MLX 無法載入，程式會提供訊息並可改用 CPU。

v2.7.7 發行包已整合 PyAV 音訊解碼與執行 MLX 所需的元件。**使用發行版不需安裝 Python、FFmpeg 或 mlx-whisper。**

## 第一次轉錄

1. 點選「加入檔案...」，或把影音檔案拖曳到主視窗。支援 MP4、MP3、MKV、WAV、MOV、AVI、M4A、FLAC、OGG、WEBM。
2. 在「準確度（Model）」選擇模型。尚未下載的模型會標示 `[未下載]`；開始轉錄時會自動下載，也可以先按「下載模型」。
3. 選擇運算單元與輸出格式。一般轉錄用途建議先使用 `large-v3-turbo` 與 SRT；若要翻譯成英文，請依下方說明改選其他模型。
4. 視內容決定是否勾選「強制繁體中文」，並填入前導提示或熱詞。
5. 點選「開始轉錄（Start）」。清單中的檔案會依序處理，底部顯示目前進度與日誌。
6. 完成後可開啟字幕、開啟所在資料夾或進入「字幕校對」。輸出檔預設與原始影音放在相同資料夾，檔名相同、附檔名改為所選格式。

如果選用尚未快取的模型，第一次執行時間會包含模型下載；這不代表轉錄停住。可從進度文字查看下載量、速度與預估剩餘時間。

## 模型選擇指南

| 模型 | 預估大小 | 適合情境 |
| --- | ---: | --- |
| `tiny` | 約 75 MB | 快速測試、硬體資源有限，準確度較低 |
| `base` | 約 145 MB | 短內容與初步草稿 |
| `small` | 約 480 MB | 一般語音與速度優先的工作 |
| `medium` | 約 1.5 GB | 速度與準確度的平衡 |
| `large-v3` | 約 3.1 GB | 準確度優先，需更多記憶體與時間 |
| `large-v3-turbo` | 約 1.6 GB | **一般轉錄建議**；兼顧辨識品質、速度與資源需求 |

實際速度與記憶體用量會受到影片長度、語言、CPU／GPU、散熱及其他執行中程式影響，表格不代表所有硬體都能得到相同效能。

## 完整轉錄設定

### 運算單元

- **Windows `cpu`**：相容性最高，不需要額外驅動設定。
- **Windows `cuda`**：選用的 NVIDIA GPU 加速。需要相容的驅動與 cuDNN；請參考 [NVIDIA cuDNN](https://developer.nvidia.com/cudnn) 與 [CTranslate2 安裝文件](https://opennmt.net/CTranslate2/installation.html)。若載入失敗，切換回 `cpu`。
- **macOS `cpu`**：使用處理器轉錄，適合作為相容模式。
- **macOS `mlx`**：使用 Apple Silicon 的 MLX 加速。官方 DMG 已包含所需執行元件。

### 輸出格式

- **SRT**：最通用的字幕格式，包含序號與時間軸。
- **VTT**：適合 HTML5 網頁播放器及部分教學平台。
- **TXT**：只保留文字，方便閱讀、摘要與後續潤飾。
- **TSV**：以欄位方式保存時間與文字，適合試算表或資料處理。
- **JSON**：保留結構化結果，適合程式整合。

### 強制繁體中文與翻譯英文

「強制繁體中文」會在中文辨識後使用 OpenCC 轉為台灣慣用繁體文字。它不會代替人工校對，也不會修正所有專有名詞。

自 v2.7.15 起，啟用時會先檢查繁體轉換元件，任務日誌會顯示「強制繁體中文：已啟用 OpenCC」。若元件未成功載入，會在模型初始化前停止並顯示原因，不會默默輸出未轉換的字幕。Windows 安裝版與免安裝版均已修正相依 DLL 的封裝；更新前請先關閉舊程式。前導提示用於引導辨識內容，不能代替這個輸出後處理步驟，無須為了強制繁體而移除自訂提示。

「翻譯為英文」會要求 Whisper 執行英文翻譯；啟用時，「強制繁體中文」不適用。需要保留原語言字幕時，不要勾選英文翻譯。

`large-v3-turbo` 不適合「翻譯為英文」：該模型未針對翻譯任務訓練，可能仍輸出原語言。需要英文翻譯時請改選 `medium` 或 `large-v3` 等支援翻譯的多語模型。

### 前導提示與熱詞補強

- **前導提示（Prompt）**：輸入一段完整語句描述講題、情境或文風，例如「這是一堂介紹資料庫索引的資訊工程課程」。它用來建立整體上下文。
- **熱詞補強（Hotwords）**：輸入以逗號分隔的人名、術語、產品名稱或程式識別字。也可以按「載入」，從每行一詞或逗號分隔的文字檔匯入，內容會與現有熱詞合併。

若同時啟用「強制繁體中文」，程式會把繁中引導語與自訂前導提示合併。提示與熱詞只能提高模型注意這些內容的機會，仍可能出現同音字或錯誤拼寫。

在 v2.7.7 中，Windows `cpu`／`cuda` 與 macOS `cpu` 使用的 faster-whisper 會把前導提示與熱詞送入辨識引擎。macOS `mlx` 只會把前導提示送入 MLX 辨識引擎；熱詞不會引導 MLX 辨識，只會參與後續文字處理。MLX 也不會把 VAD 靜音過濾與單字時間戳選項送入辨識引擎。若工作需要這些控制，請在 macOS 改用 `cpu`。

### 進階設定

按「顯示進階設定」可調整 VAD 靜音過濾、單字時間戳、文字間距、英文大小寫修正、CPU 執行緒、標點處理及斷句策略。預設的自然語意與停頓斷句會參考語音停頓、標點與單字時間軸；防溢上限預設為 35 字，用來避免單條字幕過長，但不是強制每句都等長的硬切規則。

除非已理解用途，建議先保留預設值。語音過短、背景噪音很大或音樂占比高時，調整 VAD 仍不一定能消除所有幻覺文字。

## 多檔案批次處理

可以重複按「加入檔案...」或一次拖入多個檔案。程式會過濾不支援的格式、依清單順序處理，並在日誌顯示目前檔案及整批進度。

- 按「清除清單」可在開始前移除所有待處理項目。
- 執行中按「取消（Cancel）」並確認，可停止目前批次任務；已完成的輸出會保留。
- 批次完成視窗會逐項提供「開啟字幕」、「開啟目錄」與「字幕校對」。
- 少量或大量檔案會使用適合的完成清單版面；這不影響輸出內容。

## 字幕校對器

按主畫面的「編輯現有字幕檔」，或在任務完成視窗按「字幕校對」，即可開啟 SRT、VTT 或 TXT。SRT／VTT 以時間軸清單編輯；TXT 使用全文模式。

### 影音同步預覽與播放控制

選擇與字幕對應的影片後，點選任一字幕列會跳到該時間；播放時，字幕清單會跟隨目前畫面。右側播放器提供：

- 播放／暫停與前後 5 秒跳轉。
- `1.0x`、`1.25x`、`1.5x`、`2.0x`、`0.75x` 循環播放速度。
- 音量滑桿與一鍵靜音；解除靜音會回復先前音量。
- 「CC」開關，在影片畫面上疊加目前字幕，文字修改後同步更新。
- 分割面板可拖曳調整字幕與影片區域；按 F11 或視窗按鈕可切換最大化。

若未選影片，仍可編輯字幕文字與時間軸。

### 編輯時間與文字

先選取字幕列，再在下方修改開始時間、結束時間與文字。可用 `-0.5s`、`+0.5s` 快速微調時間，或用「上一條（Alt+↑）」與「下一條（Alt+↓）」連續校對。搜尋欄會協助定位含有指定文字的字幕。

編輯後按「儲存並關閉（Save & Close）」寫回原檔；關閉前請確認時間格式與文字內容。

自 v2.7.8 起，字幕儲存與 EverCam 部署會拒絕相關輸出路徑中的符號連結或 Windows junction／reparse point，避免覆寫非預期檔案。若收到拒絕訊息，請先確認來源可信，再把需要的內容複製成一般檔案／資料夾後重試。EverCam 首頁備份失敗時會停止部署；重新部署會保留原首頁備份與額外自訂資源。單一檔案會安全替換，但整批部署不保證全部成功或全部復原；磁碟空間不足時請保留備份並排除原因後重試。

### 分割、合併與鍵盤操作

- **Ctrl+K**：把文字游標放在目前字幕文字中間，依前後文字比例將該字幕與時間軸分成兩條。
- **Ctrl+J**：把目前字幕與下一條合併，文字及起訖時間會接合並重新編號。
- **Alt+↑／Alt+↓**：切換上一條／下一條字幕。
- **空白鍵**：播放或暫停影音預覽。
- **F11**：切換字幕編輯器最大化狀態。

分割前請把游標放在合適位置；最後一條字幕無法再與下一條合併。操作後仍需播放檢查時間點。

## 模型儲存管理

主畫面右下角的「模型儲存管理」提供以下功能：

- 顯示目前模型快取路徑與磁碟剩餘空間。
- 以 `[已下載]`／`[未下載]` 標示模型狀態，並列出預估大小。
- 點「立即下載」預先快取模型；下載支援取消與斷點續傳，再次下載可繼續未完成內容。
- 變更模型儲存路徑，例如把模型移到空間較大的磁碟。變更路徑不等同自動搬移舊快取；請在新路徑重新確認模型狀態。
- 清除指定模型快取以釋放空間；之後使用該模型時需要重新下載。

預設快取通常位於 Windows 的 `C:\Users\使用者名稱\.cache\huggingface\hub`，或 macOS 的 `/Users/使用者名稱/.cache/huggingface/hub`。若預設路徑無寫入權限，程式會提示改用其他可寫入位置。

## 離線使用

離線前先在「模型儲存管理」下載需要的模型，確認選單顯示 `[已下載]`，並用一小段影音完成測試。離線環境下可轉錄、校對字幕及進行 EverCam 網頁轉換，但無法下載新模型或檢查 GitHub 最新版本。

若離線時誤選未下載模型，程式會顯示網路／模型載入說明並恢復介面，不應直接關閉程式。改選已下載模型即可繼續。

## EverCam 數位課程

v2.7.9 起主入口整合為「網頁播放器」→「EverCam 課程轉換」。v2.7.8 仍顯示原入口名稱。

程式可辨識包含 EverCam `config.js` 與影音檔的課程資料夾：

若課程已經有字幕，不必重新轉錄。可直接在主畫面按「網頁播放器」→「EverCam 課程轉換」開啟獨立工具，再選擇單一課程資料夾、使用「批次掃描母目錄」尋找多個課程，或把課程資料夾拖入視窗。

v2.7.10 起，轉換視窗也可直接拖入課程內的影片檔，會自動尋找所屬 EverCam 課程。一般 MP4 若不屬於 EverCam，請使用「一般影片＋字幕」。工具列、課程資訊與操作按鈕分行排列，長路徑會換行；不必縮小系統字體來找按鈕。

播放器會讀取課程目錄中的 `media.srt`、`media.vtt`、`media.<語言>.srt` 或 `media.<語言>.vtt`。TXT、TSV 與 JSON 不能直接提供播放器需要的字幕時間軸；若要先由本程式轉錄再建立 EverCam 播放器，請選擇 SRT 或 VTT。

多語字幕可命名為 `media.zh-TW.srt`、`media.en.srt`、`media.ja.vtt`。完整語言選擇請參閱下方的[常見語系代碼對照表](#常見語系代碼對照表)；下方範例同樣以 `media` 為主檔名。未標語系的 `media.srt`／`media.vtt` 會作為繁體中文 `zh-TW`，不是自動辨識字幕語言。

1. 把整個課程資料夾拖入主畫面，或選擇課程內的影音檔／`config.js`。程式會向上尋找課程根目錄並標示 EverCam 課程數量。
2. 依一般流程產生字幕。完成視窗會為 EverCam 項目顯示專屬徽章與「EverCam網頁轉換」。
3. 單一課程可立即轉換；多個課程可按「一鍵轉換全部的 EverCam 網頁」。
4. 轉換器會把字幕標準化到課程目錄、原生產生 `subtitles-data.js`，並部署可搜尋、可切換字幕且支援行動裝置的 HTML5 播放器。
5. 第一次替換既有首頁前，原始 `index.html` 會備份為 `index.evercam-original.html`。已是新播放器或已存在備份時，不會重複覆蓋原始備份。
6. 完成後程式會用預設瀏覽器開啟新播放器供立即檢查。

請保留整個課程資料夾結構，不要只移動新的 `index.html`。若檔案權限不足，請把課程複製到自己可寫入的位置後再轉換。

### 網頁播放器的逐字稿搜尋

EverCam 播放器右側以「章節／逐字稿」分頁呈現閱讀內容，預設顯示章節。點「逐字稿」即可搜尋字幕，點「章節」返回索引；切換分頁不會改變播放時間，也會保留搜尋字詞及所選語言。

「一般 MP4＋字幕」沒有章節索引，預設先收合逐字稿側欄。按播放器下緣右側的「逐字稿與搜尋」即可開啟右側的「逐字稿」分頁，再次按同一個按鈕可收合；不會顯示空白的章節分頁。手機及窄視窗會將閱讀面板放在影片下方。

1. 切到「逐字稿」分頁後，在搜尋欄輸入字幕中的關鍵字，即可看到符合的字幕段落與開始時間；英文搜尋不區分大小寫，符合文字會標示底色。
2. 點選任一結果，影片就會跳到該段字幕的開始時間並播放。清除搜尋可恢復完整逐字稿。
3. 切換 CC 字幕語言時，逐字稿也會切換。也可用「逐字稿語言」單獨選擇要搜尋的語言；即使關閉畫面上的字幕，仍可搜尋與閱讀逐字稿。
4. 長逐字稿先顯示 100 段，再按「顯示更多」繼續閱讀。搜尋會比對整份所選語言字幕，不只搜尋已顯示的段落。
5. 搜尋欄下方的「跟隨播放」預設不勾選。勾選後，播放器會標示目前字幕，當該段移出視野時，只捲動逐字稿清單，不捲動整個頁面；拖曳播放進度、快轉、倒退或切換逐字稿語言後也會定位對應字幕。
6. 輸入搜尋字詞期間暫停自動跟隨，保留搜尋結果；清除字詞後恢復。取消勾選可自由閱讀，不會改變影片播放時間。
7. 跳到長逐字稿的後段時，跟隨會自動顯示當前段落附近的 100 段，不必先反覆按「顯示更多」。取消跟隨後可按「顯示前段」或「顯示更多」往前、往後瀏覽。沒有字幕時無法啟用；逐字稿收合或切到章節分頁時不會自動展開或捲動。

逐字稿來自已加入的字幕，不會重新辨識音訊或翻譯；沒有字幕時會顯示提示。搜尋可在本機離線執行。既有輸出網頁須重新轉換 EverCam 課程，或用「編輯既有網頁…」重新匯出一般影片包，才能取得新的播放器功能。

### 閱讀設定與完整逐字稿下載（自 v2.8.0 起）

本節適用本工具輸出的「一般 MP4＋字幕」及 EverCam 播放器；OpenCam 沿用原播放器，不會被替換。已經輸出的舊網頁不會自動取得新功能，需要重新建立／部署。

- **字幕外觀**：在影片的 **CC → 字幕外觀** 調整字級、白字黑底／黃字黑底／黑字白底等樣式，以及字幕位置。無底色字幕的對比會受影片畫面影響，建議閱讀需要較高對比時使用有底色樣式。
- **逐字稿閱讀**：展開逐字稿，在上方提示文字旁按 **閱讀設定**。可選 100%、125%、150%、200% 字級、1.5／1.8／2 倍行距，以及選用的頁面高對比。預設維持原有配色與版面；按「恢復預設」可還原。設定盡可能保存在目前瀏覽器，若瀏覽器不允許本機網頁儲存，當次仍可使用，但重開後可能回到預設。
- **完整下載**：先選「逐字稿語言」，在閱讀設定內按 **閱讀版 HTML** 或 **純文字 TXT**。下載該語言全部字幕，不受搜尋、已載入頁數或「跟隨播放」影響；沒有可用內容時下載按鈕停用。時間標記預設不加入，需要時可勾選「包含時間標記」。HTML 閱讀版可離線開啟，具有標題、語言及可用章節，亦可使用瀏覽器列印／另存 PDF。
- **快速定位**：定位連結平時隱藏，從頁面第一個 Tab 停留點可依序選取，取得鍵盤焦點時才顯示，按 Enter 跳轉。亦可使用定位快捷鍵（Accesskey）：C＝播放器、I＝章節、T＝逐字稿、H＝展開操作說明。Windows Chrome／Edge 使用 Alt＋代碼，Firefox 使用 Alt＋Shift＋代碼；macOS Chrome／Safari／Firefox 使用 Control＋Option＋代碼。定位會切換分頁、展開逐字稿並移動焦點，再按 Tab 即可操作內容。一般 MP4 或沒有章節的課程不提供 I 定位鍵。若組合鍵已由瀏覽器或輔助工具使用，可改用 Tab 選取定位連結。
- **播放快捷鍵**：先選「跳至播放器」或點影片畫面。影片畫面取得焦點時，Space 播放／暫停，←／→ 快退／快轉 10 秒；影片畫面或一般控制按鈕取得焦點時，M 切換靜音、F 切換全螢幕。按鈕上的 Space／Enter 仍執行該按鈕功能；搜尋欄、滑桿、下拉選單及字幕設定保留原生按鍵，不會誤觸播放快捷鍵。按住 M 或 F 不會連續切換。
- **控制項與選單**：Tab／Shift + Tab 巡覽，Enter／Space 啟用按鈕。CC 與速度按鈕也可用 ↓ 開啟；速度清單以 ↑／↓、Home／End 移動，Enter／Space 套用。CC 設定以 Tab 巡覽語言及外觀選項。Esc 關閉選單或閱讀設定並回到原按鈕；Tab 可直接離開。進度與音量滑桿使用方向鍵與 Home／End，提供可理解的時間／百分比。窄螢幕未顯示音量滑桿時，可使用裝置音量鍵。
- **完整操作說明**：播放器下方的「操作說明與鍵盤快捷鍵」預設收合，按 Enter／Space 或點選即可展開，手機也可閱讀。內含「快速定位與基本操作」、「播放、音量與全螢幕」、「字幕、速度與選單」、「章節、逐字稿與閱讀設定」四個可獨立展開的小節。用 Tab 選取小節標題，再按 Enter／Space 展開或收合。在說明區按 Esc 可收合整個說明並回到入口。
- **輔助閱讀**：頁面提供可見焦點、縮放排版、減少動態及系統強制色彩模式的相容處理。播放跟隨不會將每條字幕設定為即時朗讀，也不會強迫改變鍵盤焦點。

依 [W3C 逐字稿指引](https://www.w3.org/WAI/media/av/transcripts/)，閱讀版依段落整理字幕，時間標記只在需要時加入。字幕未包含的講者身分、重要聲音及未口述的畫面資訊，仍需由教師檢查並補充；本工具不會自動猜測。這些功能以 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 相關準則為改善目標，不代表每份課程內容或整站已取得 AA 認證；自動檢測也不能取代螢幕閱讀器與實際使用者測試。

鍵盤、焦點與定位操作亦參考台灣[網站無障礙規範（110.07）](https://accessibility.moda.gov.tw/Accessible/Guide/68) 的 2.1.1 鍵盤、2.1.2 無鍵盤操作陷阱、2.1.4 快捷鍵，以及 2.4.1 跳過區塊、2.4.3 焦點順序與 2.4.7 焦點可視。單一字元播放快捷鍵限播放器內合適的焦點位置啟用。

## OpenCam 網頁播放器字幕置入

自 v2.7.13 起支援 [OpenCam](https://github.com/kaoshou/OpenCam) 輸出的網頁播放器資料格式 `opencam.web-player`、`schemaVersion: 1`。專案資料夾須包含 `index.html`、`media.mp4` 與 `opencam-player.js`。**不必轉換播放器或重製影片**，只把字幕時間軸置入原有資料檔；標題、章節、其他語系字幕與網頁外觀均會保留。

### 從影片轉錄後置入

1. 將 OpenCam 網頁資料夾、`media.mp4`、`index.html` 或 `opencam-player.js` 拖入主畫面，程式會載入對應的 `media.mp4`。同資料夾內其他 MP4 不會被誤認為此專案。
2. 輸出格式選擇 SRT 或 VTT，再依一般流程轉錄。目前播放器置入功能只接受 SRT／VTT，TXT、TSV、JSON 不會顯示置入按鈕。
3. 轉錄完成後，結果清單會在檔名後標示「OpenCam 播放器」，不再另外詢問或自動修改播放器。需要置入時，按該列的「OpenCam 置入字幕」，開啟預填本次字幕的設定視窗；也可稍後從首頁的「網頁播放器」開啟。
4. 確認字幕語系，按「備份並置入字幕」，完成後按「預覽播放器」。翻譯英文的轉錄結果會預填 `en`；沒有語系標記的字幕使用 `und`（預設字幕），不會猜測為繁體中文，可手動改為 `zh-TW` 等代碼。

### 已有字幕，不必重新轉錄

1. 主畫面按「網頁播放器」→「OpenCam 置入字幕」。
2. 選擇或拖入 OpenCam 專案資料夾／`media.mp4`。程式會讀取同資料夾的 `media.srt`、`media.vtt`、`media.zh-TW.srt`、`media.en.vtt` 等檔案；同語系同時有 SRT 與 VTT 時優先使用 VTT。
3. 可以一次加入多種語系，也可用「加入 SRT／VTT 字幕…」選擇其他位置的字幕，或拖入字幕檔。每個新字幕語系只能有一個檔案；語系選單可直接輸入有效代碼，如 `vi`、`my`、`pt-BR`。完整代碼見[常見語系代碼對照表](#常見語系代碼對照表)。
4. 按「備份並置入字幕」。**已有相同語系時更新該軌字幕，其他語系完整保留**；原本的預設字幕軌不變。沒有字幕（包含 `subtitles: null`）的專案會建立第一軌字幕，並將其設為預設。

播放器的 CC 選單與逐字稿分頁會直接使用置入的多語資料。原 OpenCam 播放器若記住「關閉字幕」偏好，請在 CC 選單重新選擇語言。逐字稿搜尋與章節切換沿用原 OpenCam 的操作方式；本工具不替換 `index.html`。

### 備份與限制

每次置入前，原始 `opencam-player.js` 都會完整備份到同資料夾，檔名為 `opencam-player.backup-<時間>-<識別碼>.js`，不同次備份不會互相覆蓋。若要還原，先保留目前資料檔，再把所需備份複製回 `opencam-player.js`，重新載入網頁即可。

格式、字幕或語系驗證失敗時不會寫入；備份失敗時也不會替換原資料檔。持續遭到 Windows 檔案占用時會保留原檔與已建立的備份，請關閉可能占用檔案的編輯器／同步工具後重試。本功能使用安全檔案操作，拒絕符號連結與重新解析點，不執行匯入的 JavaScript。依 OpenCam 格式限制，最多 32 軌字幕、每軌 100,000 段、每段 10,000 字元；播放器資料檔最多 32 MiB。

## 更新程式

「關於本程式」會顯示目前版本並提供「檢查更新」。程式只向 GitHub 查詢版本資訊；若有新版，可前往官方 Releases 下載。更新前先關閉正在執行的轉錄與模型下載工作。

Windows 直接以新版 EXE 取代舊檔；macOS 重新掛載新版 DMG，將 App 拖入「應用程式」並選擇取代。Whisper 模型通常存放在獨立快取目錄，更新程式本身不會主動清除它們。

## 常見問題

### 模型下載失敗或顯示離線

確認網路可連至 Hugging Face，稍後再試。已下載一部分的模型通常可續傳。若程式判定快取損毀，可依提示清除該模型快取後重新下載。

### 磁碟空間不足或沒有寫入權限

開啟「模型儲存管理」，選擇空間充足且自己可讀寫的資料夾。Windows 路徑過長時，可改用較短的位置，例如 `D:\models`。

### Windows CUDA 無法使用

確認 NVIDIA 驅動、CUDA／cuDNN 與 CTranslate2 支援版本相容。CUDA 不是必要條件；切回 `cpu` 可繼續轉錄。

### macOS MLX 載入失敗

先確認使用的是官方 v2.7.7 或更新 DMG，並把 App 完整複製到「應用程式」。重新開啟後仍失敗時，可先選 `cpu` 完成工作，再到 GitHub Issues 提供 macOS 版本、晶片型號與日誌中的完整錯誤。

### 字幕內容不準確或斷句不理想

改用較大的模型，提供講題前導提示與專有名詞熱詞，並確認音訊清楚。完成後使用字幕校對器修正文字與時間軸；任何模型都不能保證完全正確。

### 字幕編輯器沒有聲音或畫面

確認選到與字幕對應且格式受支援的影音檔，檢查播放器音量與靜音狀態。仍無法播放時，可先在編輯器完成文字校對，並在 Issues 附上格式與錯誤日誌。

## 一般 MP4＋字幕匯出網頁

自 v2.7.9 起提供，不需要 EverCam 專案，也不必重新轉錄。

1. 按「網頁播放器」→「一般影片＋字幕」。
2. 按「選擇 MP4 影片」。程式自動讀取**同資料夾**內同檔名或加語系碼的 UTF-8 SRT／VTT 字幕，主畫面只顯示已讀入的字幕摘要，不必逐一加入或選語言。
3. 按「建立網頁 →」。標題取自影片檔名，輸出另存於影片旁的新資料夾；一般情況不再要求二次確認，只有相容性等警告需確認。完成後按「開啟網頁」。

v2.7.10 起，支援直接把 **一個 MP4** 拖入這個視窗，自動配對規則與按鈕選檔相同。可一起拖入 SRT／VTT，或選好影片後補拖字幕；不支援一次建立多部影片網頁。正在檢查／匯出時請先等候完成或取消；拖入不支援的檔案不會清掉已選內容。拖放元件未啟用時會顯示提示，仍可用選檔按鈕完成操作。

### 字幕檔名與自動配對規則

**只有一份字幕時，把字幕和 MP4 放在同一資料夾，使用相同主檔名即可。**例如 `media.mp4` 搭配 `media.srt`，不必另外設定語系。若有多個語言版本，則在主檔名後面加上「半形句點＋語系代碼」。

```text
影片主檔名.語系代碼.srt
影片主檔名.語系代碼.vtt
```

以下統一以 `media.mp4` 為例；一般影片可使用自己的主檔名，字幕需跟著使用相同主檔名。資料夾可以這樣安排（只需放入實際擁有的字幕，不必準備所有語言）：

```text
教材資料夾/
  media.mp4
  media.zh-TW.srt
  media.en.srt
  media.ja.vtt
  media.vi.srt
```

選好影片後，程式就會自動加入繁體中文、英文、日文與越南文字幕軌，觀看者可在匯出的網頁中切換；不是把四種字幕同時疊在畫面上。

- **主檔名要一致**：`media.mp4` 應搭配 `media.en.srt`。請直接複製影片主檔名，保留空格、標點與大小寫；不要寫成 `media.mp4.en.srt`。
- **使用半形符號**：主檔名與語系間用句點 `.`，語系內用連字號 `-`，例如 `media.zh-TW.srt`；不要用 `media_英文.srt`、`media.zh_TW.srt` 或全形句點。
- **字幕格式與文字編碼**：只自動配對 UTF-8 的 SRT／VTT。語系代碼不是文字編碼；把 TXT 改名為 `.srt` 不會產生字幕時間軸。
- **沒有語系碼**：`media.srt` 或 `media.vtt` 顯示為「預設字幕」，內部使用 `und`（語言未指定），不猜測內容語言。它可與 `media.en.srt` 等具名字幕並存；如果都是同一份繁中內容，保留其中一份即可，避免重複字幕軌。
- **同語系只加入一份**：例如同時存在 `media.en.srt` 與 `media.en.vtt`，自動配對優先採用 VTT。`en` 和 `en-US`、`zh-TW` 和 `zh-Hant` 是不同代碼，不會自動合併成同一軌。
- **配對範圍**：只找影片所在資料夾，不掃描子資料夾，也不跟隨符號連結。`media2.srt`、`其他影片.en.srt` 不會配給 `media.mp4`。找不到字幕時，請放好檔案後重新選擇影片。

### 常見語系代碼對照表

下表可直接套用在字幕檔名中；範例使用 SRT，也可以換成真正的 VTT 字幕。一般情況使用簡短的語言代碼即可，只有需要區分地區或文字系統時才加後綴。

| 繁體中文（台灣） | `zh-TW` | `media.zh-TW.srt` | 本程式內建繁中選項；只區分繁體字形可用 `zh-Hant` |
| 簡體中文（中國大陸） | `zh-CN` | `media.zh-CN.srt` | 本程式內建簡中選項；只區分簡體字形可用 `zh-Hans` |
| 英文 | `en` | `media.en.srt` | 美國英文 `en-US`、英國英文 `en-GB` |
| 日文 | `ja` | `media.ja.srt` | 使用 `ja`，不是國家代碼 `jp` |
| 韓文 | `ko` | `media.ko.srt` | 使用 `ko`，不是國家代碼 `kr` |
| 越南文 | `vi` | `media.vi.srt` | 使用 `vi`，不是國家代碼 `vn` |
| 印尼文 | `id` | `media.id.srt` | 使用現行代碼 `id`，不要用舊代碼 `in` |
| 泰文 | `th` | `media.th.srt` | 不需區分地區時用 `th` 即可 |
| 緬甸文 | `my` | `media.my.srt` | `my` 是緬甸文；馬來文是 `ms` |

| 俄文 | `ru` | `media.ru.srt` | 不需區分地區時用 `ru` 即可 |
| 法文 | `fr` | `media.fr.srt` | 法國法文 `fr-FR`、加拿大法文 `fr-CA` |
| 德文 | `de` | `media.de.srt` | 不需區分地區時用 `de` 即可 |
| 義大利文 | `it` | `media.it.srt` | 不需區分地區時用 `it` 即可 |
| 馬來文 | `ms` | `media.ms.srt` | 與印尼文 `id`、緬甸文 `my` 不同 |
| 菲律賓文 | `fil` | `media.fil.srt` | 三字母語言代碼；他加祿文另有 `tl` |
| 印地文 | `hi` | `media.hi.srt` | 使用 `hi`，不要以國家代碼代替語言 |
| 阿拉伯文 | `ar` | `media.ar.srt` | 匯出後請在目標瀏覽器確認由右至左文字的顯示 |

`zh-TW`／`zh-CN` 標示地區，`zh-Hant`／`zh-Hans` 標示繁體／簡體文字系統，含義並不完全相同。例如香港繁體中文可用 `zh-Hant-HK`。語系通常寫成小寫語言、大寫地區、首字大寫文字系統，例如 `en-US`、`zh-Hant`；程式會將受支援代碼的大小寫標準化。命名概念可參閱 [W3C 語言標籤說明](https://www.w3.org/International/articles/language-tags/)，代碼可查閱 [IANA 語言子標籤登錄表](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry)。

**改檔名不會翻譯字幕，也不會把簡體字轉為繁體字。**`media.en.srt` 應該已經含有英文字幕；請先完成翻譯與校對，再依實際內容命名。上表是字幕軌的標示方式，不是模型辨識品質或自動翻譯語言的保證。

### 手動調整語系與預設字幕

自動配對後若需要更換語系，展開「進階設定（選填）」調整字幕軌的語言。選單沒有列出的語言可直接輸入代碼，例如 `vi`、`my` 或 `pt-BR`；未內建中文名稱的代碼可能直接以代碼顯示。一般影片匯出支援「2～3 字母語言＋可選的 4 字母文字系統＋可選的 2 字母或 3 數字地區」，不是所有 BCP 47 延伸標籤都能使用。

EverCam 課程使用相同語系代碼，但字幕主檔名固定為 `media`，例如 `media.zh-TW.srt`、`media.en.vtt`。**EverCam 的無語系 `media.srt`／`media.vtt` 會作為 `zh-TW`；一般 MP4 的無語系字幕則是 `und`。**有其他語言的 EverCam 字幕時，請加上正確代碼，不要依賴無語系檔名。

需要調整時才展開「進階設定（選填）」，可改標題、作者、單位、純文字簡介、PNG／JPEG 封面、儲存位置、新資料夾名稱及預設字幕，也能移除某軌後手動加入替代檔案。「自動（第一個字幕）」為預設：沒有手動加入其他軌時，優先顯示無語系的「預設字幕」，否則依自動載入順序；亦可指定某軌或「不顯示字幕」。語言選單可輸入受支援的代碼，例如 `pt-BR`。

標題預設取影片檔名；手動修改後不會因換影片而被覆蓋，可按「恢復影片檔名」恢復。手動設定的儲存位置、資料夾名稱與字幕也會保留；自動配對不會取代手動指定的同語系字幕。換影片只會移除尚未手動調整的自動配對字幕。自動命名遇到同名資料夾會加流水號；手動指定的名稱不會被擅自更改。標題、作者、單位、簡介最多分別為 200、100、200、5,000 字元；選填欄位留白便不顯示。封面限制 20 MiB／2,500 萬像素，會重新編碼去除非必要中繼資料。

一般模式不顯示章節側欄。多語字幕是切換字幕軌，不是雙語並列；不自動產生章節、標題或摘要。MP4 容器不代表所有瀏覽器都支援其中編碼，本工具不重新編碼，遇到相容性提示時應先用目標瀏覽器試播。

輸出會完整複製影片、字幕與播放器資源。請保留並一起移動整個資料夾；可直接開啟 `index.html`，或自行上傳靜態網站。不需要 CDN／帳號，不會自動上傳。字幕來源單檔上限 32 MiB，影片採分塊複製，不整檔載入記憶體。

若要修改，使用「編輯既有網頁…」讀取包內 `web-export.json`，會建議新的資料夾名稱，仍可自行調整位置。重新匯出只另存新資料夾，舊包不變；不複製使用者自行加入的 HTML／JS。缺檔時可重新選來源，缺失字幕可移除後重新加入。設定檔上限 1 MiB，不接受外部 URL、符號連結或不支援的版本。

目的資料夾必須不存在，即使空資料夾也不覆寫。取消／錯誤後，已寫入內容的暫存包會保留並顯示位置；只會自動移除空暫存資料夾。這是為了避免清理時遇到檔案被替換而誤刪，代價是部分影片副本仍占用磁碟；請確認訊息所指位置與內容後自行處理。測試範圍與尚未覆蓋的瀏覽器情境見 [驗證紀錄](https://github.com/kaoshou/Video-to-Subtitle/blob/main/docs/testing/standalone-web-export.md)。

### Windows 顯示檔案被占用（WinError 32／33）

v2.7.10 已對寫入發布時的短暫占用加入有限次重試（每個操作最多等待約 4.55 秒）。若占用持續，請關閉可能正在開啟該檔案的程式，稍候重試；不要停用安全防護。無法僅憑錯誤訊息判定是哪個程式占用。

v2.7.11 進一步移除一般影片匯出包內 `content → index.html` 等逐檔改名步驟：各資源直接建立於未發布的暫存包，所有寫入完成並關閉檔案後才整包發布。這避免了該逐檔改名的共享衝突路徑，但不表示任何檔案占用、權限或磁碟問題都可忽略。Windows 共享衝突也可能來自同一程式或背景服務；不需要您主動開啟其他應用程式才會發生。若仍失敗，請提供「查看錯誤詳細資訊」內的程式版本、失敗階段（若有）、資源名稱及完整錯誤；可稍候重試或改選其他輸出資料夾，不要停用安全防護。

主畫面只顯示簡短原因；按「查看錯誤詳細資訊」可檢視及選取複製完整錯誤與保留暫存位置。存取權限不足、目的檔已存在及不安全路徑不會視為短暫占用重試，也不會因此繞過符號連結防護。

### EverCam 轉換按鈕沒有出現

確認選取的資料夾或上層目錄包含 `config.js` 與課程影音檔。一般影音不是 EverCam 專案，不會顯示此按鈕。

## 從原始碼執行

> 本節只供開發者使用。一般使用者應下載 Releases 的 EXE 或 DMG。

建議使用 Python 3.11（專案支援 Python 3.10 至 3.12）。建立虛擬環境後安裝核心依賴：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
pip install customtkinter tkinterdnd2 faster-whisper opencc av pillow sounddevice pyinstaller
```

macOS 開發者若要從原始碼使用 MLX，再安裝：

```bash
pip install mlx-whisper
```

啟動與打包：

```bash
python SubtitleTranscriber.py
pyinstaller VideoToSubtitle.spec
```

成品位於 `dist/VideoToSubtitle.exe` 或 `dist/VideoToSubtitle.app`；macOS 正式 DMG 仍以專案 CI 產物為準。
