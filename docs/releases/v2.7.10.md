# v2.7.10：網頁匯出穩定性與原生介面改善

## 修正與改善

- Windows 建立字幕網頁遇到短暫檔案占用（WinError 32／33）時有限次重試；持續占用顯示簡短提示與可展開的完整錯誤。保留原子寫入、不可覆寫及符號連結防護。
- 一般 MP4 與 EverCam 轉換視窗可拖入影片；一般 MP4 自動讀取同資料夾的同名／語系 SRT、VTT，不需重做字幕。
- EverCam 標題、工具列與操作區分行，改善長路徑與高縮放下的按鈕遮蔽。
- 修正 macOS 選影片後出現黑色 `!dropdownmenu` 視窗；保留字幕語系選單與檔案拖放。
- 主視窗進階設定展開後自動捲入可見區，收合後回復原捲動位置，保留所有參數。
- 模型管理「完成」按鈕加高，下載進度與取消下載保留完整空間。
- 統一繁體中文字體、深淺色配色；字幕編輯器底部按鈕與表格字體支援介面縮放。

## 下載與說明

- Windows：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)

發布流程必須通過 Windows／macOS 回歸測試、兩平台打包及打包後網頁匯出檢查；macOS 另檢查 MLX 模組完整性。CTk 縮放幾何測試不等於所有實體螢幕與系統縮放皆已人工驗收；本次未重新執行整段語音辨識與完整瀏覽器播放矩陣。網站既有截圖仍標示實際擷取版本，並非本版新截圖。
