# v2.7.13 OpenCam 字幕置入與逐字稿搜尋

## 更新內容

- 新增「網頁播放器 → OpenCam 置入字幕」，可將 SRT／VTT 直接加入 OpenCam 原有的 `opencam-player.js`，不替換網頁、影片或章節。支援 OpenCam 網頁播放器 schemaVersion 1。
- 主畫面可選取或拖入 OpenCam 資料夾、`media.mp4`、`index.html` 或 `opencam-player.js`。轉錄完成後詢問是否置入；拒絕時不修改播放器，同意後可確認語系再執行。
- 支援原本未夾帶字幕（含 `subtitles: null`）的 OpenCam 專案，以及一次加入多種語系。相同語系更新，其他語系與原預設字幕保留；每次置入前建立完整且不覆蓋的備份。
- 防止同一程式內兩個置入視窗操作同一專案時遺失新字幕，並保留加入／拖入另一字幕前尚未提交的語系修改。語系無效或重複時顯示提示。
- EverCam 與一般 MP4＋字幕的播放器新增逐字稿搜尋、關鍵字標示、多語切換及點選時間跳轉。EverCam 右側改為「章節／逐字稿」分頁，預設章節；一般 MP4 預設收合逐字稿側欄，無空白章節分頁。
- 保留原有淺色藍綠配色與精簡頂部橫幅；窄視窗的閱讀面板移至影片下方。
- 更新繁體中文完整手冊，補充字幕檔名與語系對照、OpenCam 置入流程、備份還原與逐字稿使用說明。

## 驗證範圍

本機 macOS 原生介面完整回歸共 132 項，128 項通過、4 項 Windows 專用測試略過；播放器 11 項與網站 18 項通過。使用兩個 OpenCam 0.3.3 專案副本驗證無字幕／已有字幕、多語切換、逐字稿搜尋、跳轉與播放，原專案未修改。

正式發布須通過 Windows／macOS 完整回歸與打包成品的字幕網頁匯出檢查，以及 macOS MLX 完整性檢查。不代表已在所有硬體完成 Whisper 模型轉錄或所有瀏覽器的 `file://` 測試。OpenCam 多視窗交易鎖為同一程式內保護，不宣稱對外部程式提供原子比較／替換。
