# v2.7.12：介面層次優化與版本顯示一致性

## 更新內容

- 保留既有藍白配色，為待處理清單加入清楚的底色、邊框與留白，避免與外層背景融為一體。
- 調整轉換設定的標題、背景與欄位間距，讓進階設定有獨立的卡片層次；保留既有參數、檔案操作及轉錄流程。
- 修正程式執行期間更新原始碼時，關於本程式與標題列可能顯示不同版本的問題。所有視窗與更新檢查共用本次啟動版本，重新啟動後才採用新版本。
- 更新 README 與網站的三張 v2.7.12 實際介面截圖。截圖使用 Linux 虛擬顯示環境與合成示範素材，Windows／macOS 外觀可能略有差異。

## 驗證範圍

新增版本快取、關於視窗與更新檢查一致性、淺／深色介面區隔、小視窗及不同縮放比例的操作回歸測試。發布須通過 Windows／macOS 測試、兩平台打包後的字幕網頁匯出檢查，以及 macOS MLX 完整性檢查；不代表已在所有硬體上完成語音模型轉錄測試。
