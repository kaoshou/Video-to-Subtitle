# v2.7.16 網頁開啟與逐字稿跟隨播放

## 更新內容

- 修正 Windows「開啟網頁」只開啟 Edge、未載入轉出的網頁。改用原生絕對檔案路徑，交由 Windows 的 HTML 預設應用程式開啟；不指定固定瀏覽器、不更動預設應用程式。一般影片、EverCam 與 OpenCam 的本機網頁入口共用處理，缺少檔案或開啟失敗時顯示原因。
- 轉錄完成清單在檔名旁新增藍色「OpenCam 播放器」徽章，與 EverCam 課程徽章一致呈現。辨識依據為實際來源影片，不誤用旁邊其他影片；長檔名保留徽章與操作按鈕的空間。
- OpenCam 轉錄完成後不再另外彈出自動詢問框。需要置入字幕時，在完成清單按「OpenCam 置入字幕」，會帶入對應字幕；既有多語字幕、章節、影片及置入前備份機制保持原樣。
- 一般影片與 EverCam 網頁的逐字稿新增「跟隨播放」勾選項，放在搜尋欄下方，預設不勾選。開啟後反白目前段落，必要時只捲動逐字稿清單，不移動整個頁面；播放、跳轉、語言切換及視窗尺寸改變時更新定位。
- 搜尋期間暫停自動跟隨，清除搜尋後恢復；逐字稿收合或切換回章節時不會自動展開。跳轉到長逐字稿後段時載入目前段落附近的有限視窗，保留「顯示前段」及手動載入更多。
- 保留 v2.7.15 的強制繁體中文修正，不變更語音模型、CUDA／MLX 計算或字幕時間軸。

## 使用提醒

更新前請先關閉舊程式，更新後重新啟動。Windows 安裝版、免安裝版與 macOS 均不需另外準備 Python 執行環境。

已經轉出的網頁不會被更新程式自動改寫。一般影片請重新建立網頁；EverCam 請重新部署新版播放器並保留備份。OpenCam 採用其原有播放器，本次不替換 OpenCam 的介面或跟隨播放功能。

Windows 若未設定 HTML 預設應用程式，請先在系統設定選擇瀏覽器。首次啟動瀏覽器時，仍可能出現瀏覽器自己的初始化畫面。

## 發布驗證範圍

發布門檻包含 Windows／macOS 原生介面與檔案安全測試、播放器與網站測試，以及封裝成品的匯出、繁體轉換與 macOS MLX Metal 計算。Windows 另以真實瀏覽器載入含中文、空白及特殊字元路徑的合成 HTML，確認安裝版與免安裝版開啟的是正確頁面，而非僅啟動瀏覽器。

逐字稿另以隔離的 Chromium 與合成影片驗證一般影片／EverCam 在桌面及行動尺寸的真實清單幾何、跳轉、搜尋暫停、語言切換及重新定位。這不代表每個瀏覽器、每種影片編碼或所有 GPU 硬體都已測試；字幕仍需人工校對。測試素材為合成資料，不上傳使用者影片或字幕。
