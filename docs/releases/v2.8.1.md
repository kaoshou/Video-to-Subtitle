# v2.8.1 模型下載與 SD 卡課程轉換改善

## 修正與改善

- 改善模型下載後的完整性檢查，直接載入驗證完成的模型資料夾，減少下載完成後仍無法載入的情況。
- 模型清單區分「已下載」「下載未完成」「未下載」與「無法讀取」；缺少檔案時可接續下載，保留既有模型快取。
- 避免主畫面與模型管理視窗同時啟動下載，並統一儲存路徑的顯示、開啟與載入行為。
- 改善 Windows 不同系統語系下的中文模型路徑與錯誤提示處理。
- 保留 CPU、NVIDIA CUDA 與 Apple MLX 模型支援，改善不同 MLX 權重檔名的辨識。
- 改善 Windows 在 SD 卡與 FAT／exFAT 磁碟上的 EverCam 網頁轉換相容性，保留符號連結防護、安全寫入及原始網頁備份。
- 官網並列 Windows 免安裝版與安裝版下載，另提供 macOS 版；補充安裝版通常啟動較快的原因。

## 下載與使用

- Windows 安裝版：`VideoToSubtitle-Setup-v2.8.1.exe`
- Windows 免安裝版：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)
