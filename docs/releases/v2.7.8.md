# v2.7.8 檔案寫入安全更新

## 新增與改善

- 加強字幕編輯器的檔案寫入，原始碼預覽改在記憶體處理，儲存採用安全暫存與替換。
- 加強 EverCam 首頁備份及播放器部署，拒絕不安全的符號連結；備份失敗時保留原首頁。
- 同步保護 Windows 字幕更新工具，檢查 junction／reparse point。
- 保留多語字幕、原首頁備份與額外自訂資源。
