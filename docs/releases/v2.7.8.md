## v2.7.8 — 檔案寫入安全更新

- 修正字幕編輯器固定暫存檔可能跟隨惡意符號連結的問題；原始碼預覽改在記憶體處理，儲存使用安全暫存與替換。
- 加強 EverCam 輸出、首頁備份及播放器資源部署，拒絕不安全連結；備份失敗時停止，避免覆寫原首頁。
- 同步保護 Windows 字幕更新工具的檔案寫入，檢查 junction／reparse point。
- 保留正常字幕格式、多語字幕、原首頁備份及額外自訂資源。
- 新增 Windows／macOS 安全回歸測試，測試與雙平台打包皆成功後才自動發佈。

### 使用提醒

如遇「拒絕符號連結／重新解析點」訊息，請確認來源可信，再將內容複製成一般檔案與資料夾後重試。請勿直接刪除不明連結指向的目標。

本次不變更語音辨識模型與轉錄核心。自動化測試不等同所有硬體、檔案系統與完整 GUI 操作皆已實測。
