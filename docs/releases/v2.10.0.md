# v2.10.0｜用 AI 對話，串起字幕與多語教材

## 新增：AI 工具連接（MCP）

- **用熟悉的 AI 工具操作字幕工作流程**：可選擇啟用 MCP，讓 Codex、Claude、Gemini CLI、Antigravity、Cursor、VS Code／Copilot、OpenCode 等工具協助本機轉錄、翻譯字幕，再建立多語網頁播放器。提供工具偵測、設定、自我測試及手動設定方式；Claude Desktop 可匯出 MCPB 安裝。
- **模型由你決定，成果清楚回報**：可在對話詢問哪些模型已下載，指定模型再轉錄。首次預設 large-v3-turbo，保留既有選擇；開始前可查看模型、運算單元、批次策略與輸出規劃，完成後回報實際模型、運算單元、耗時、語言及結果位置。
- **多語翻譯可分批接續**：AI 依原字幕時間軸翻譯，支援專有名詞對照與中斷後接續缺少的批次；提供過長字幕、閱讀速度、疑似未翻譯及用詞不一致等校對提示，協助人工核對。
- **自動辨識教材類型**：辨識一般 MP4、EverCam 與 OpenCam，輸出對應播放器；保留課程章節與既有語系，新成果另建資料夾，不覆寫原始素材。
- **看得懂的工作狀態**：以檔名、中文階段、實際進度及完成摘要呈現工作，可取消處理或直接開啟成果；另提供私人工作資料管理與選用的資料夾存取限制。

MCP 預設關閉，本機轉錄不會因此改為雲端辨識。AI 翻譯可能將字幕文字送到所選 AI 服務，費用與額度依該服務而定；使用前請確認教材授權與隱私。

## 其他改善

- CPU／CUDA 批次大小可依可用記憶體、模型與硬體自動規劃，仍可手動調整；記憶體不足時保留安全回退。
- 字幕輸出依繁體中文、英文翻譯或偵測語言附加語系檔名，播放器以語言名稱顯示字幕，方便辨識多語教材。
- 改善各設定視窗的開啟位置與操作流程，統一「專有名詞」用語，提升進階設定按鈕的懸浮可讀性，更新第三方授權聲明。
