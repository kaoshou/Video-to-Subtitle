# v2.7.14 Windows 安裝版與 OpenCam 視窗改善

## 新增與改善

- 新增 Windows x64 繁體中文安裝版，內含 Python 與必要套件，保留原有免安裝 EXE 與 macOS DMG。
- 安裝時一次展開執行環境，減少後續啟動的重複解壓等待；可自訂安裝位置及桌面捷徑。
- Windows 安裝版與免安裝版共用使用者資料夾中的設定；更新、重裝與解除安裝保留設定、模型及影音。
- 修正首頁開啟 OpenCam 工具視窗後被首頁遮住的問題，開啟時自動提升至前景。

## 下載與使用

- Windows 安裝版：`VideoToSubtitle-Setup-v2.7.14.exe`
- Windows 免安裝版：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)
