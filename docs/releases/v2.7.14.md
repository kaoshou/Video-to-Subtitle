# v2.7.14 Windows 安裝版與 OpenCam 視窗修正

## 更新內容

- 正式提供 Windows x64 繁體中文安裝版，內含 Python 與必要套件，不需事先安裝執行環境。原有單檔免安裝 EXE 與 macOS DMG 繼續保留。
- 安裝版採用資料夾式封裝，安裝時解壓一次，啟動時不需反覆解壓；可選安裝位置與桌面捷徑，亦可從「開始」功能表啟動。
- Windows 封裝版設定保存於 `%LOCALAPPDATA%\VideoToSubtitle\config.json`，安裝版與新版免安裝版共用。原始碼／macOS 設定位置不變；有效舊設定只在首次建立使用者設定時遷移，不覆蓋現有設定。
- 設定讀取限制大小並拒絕符號連結／重新解析點，儲存沿用既有安全原子寫入。更新、重裝及解除安裝不刪除使用者設定、模型快取或影音。
- 修正「首頁 → 網頁播放器 → OpenCam」新視窗可能落在首頁後方：建立從屬關係，開啟時提升至前景並取得焦點；不設為全系統永遠置頂，也不新增模態鎖定。
- 更新 README、官方網站下載入口與繁體中文手冊，說明兩種 Windows 封裝的差別、設定位置、更新及解除安裝。

## 使用提醒

安裝／更新前請關閉舊程式。第一次使用某個 Whisper 模型仍需網路下載；CUDA 仍需相容 NVIDIA 顯示卡與驅動。啟動改善不代表模型載入或轉錄運算變快，無需停用防毒或設定排除項目。

預設僅安裝給目前使用者，不要求系統管理員權限。目標平台為 Windows 10／11 x64；Windows ARM 不在本次驗證範圍。安裝包未額外加入程式碼簽章，Windows 可能顯示保護提示；請確認檔案來自本專案官方 Release。

## 驗證範圍

發布門檻包含 Windows／macOS 原生介面與檔案安全完整回歸、播放器及網站測試、兩平台打包後的字幕網頁匯出、macOS 隔離主機環境的 MLX Metal 計算檢查，以及 Windows 安裝版的真實安裝、獨立啟動、重裝與解除安裝。

試用版（v2.7.13 開發分支）在同一 Windows GitHub 測試機的重複 GUI 開啟中位數為：安裝版約 **1.23 秒**、免安裝版約 **5.58 秒**。此取樣在匯出檢查之後進行，不是磁碟／防毒冷啟動，不包含模型載入或轉錄；不保證其他電腦相同速度。[試用驗證紀錄](https://github.com/kaoshou/Video-to-Subtitle/actions/runs/38423335086)。

自動安裝驗證使用 Windows x64 GitHub runner，並非所有 Windows 10／11 實體電腦的認證；不宣稱已完成所有硬體的 Whisper 模型推論。首次下載模型的網路需求不變。
