# v2.10.1 — MCP 工作管理與轉錄穩定性改善

- 修正 Windows MCP 收到辨識完成結果後，因再次讀取已關閉的通訊管線而誤報失敗的問題。
- 修正 MCP 英文翻譯模式的內部字幕檔名不一致，讓產生的字幕能正常登錄。
- 工作狀態新增「清除已完成工作」與單筆「從清單移除」，保留字幕、翻譯及播放器成果。
- 新增「失敗／中斷」篩選，方便集中查看需要處理的工作。
- 每筆工作可匯出 JSON 診斷資料，包含版本、處理階段、模型與錯誤位置，方便排查問題。
- 辨識完成後先保存實際模型、裝置與後端資訊，後續處理出錯時仍可查詢；字幕格式錯誤提供具體原因。
- 完整清理私人工作資料後立即更新工作清單，並更新 MCP 使用手冊。
