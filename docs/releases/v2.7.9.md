# v2.7.9：一般影片也能一鍵建立字幕網頁

## 新功能

- 主畫面「網頁播放器」整合 EverCam 課程轉換與「一般影片＋字幕」。
- 選擇 MP4，自動讀取同資料夾的同檔名 SRT／VTT，亦支援 `課程.zh-TW.vtt`、`課程.en.srt` 等語系字幕。同語系優先使用 VTT；無語系檔案顯示「預設字幕」。
- 標題預設取影片檔名，輸出至影片旁的新資料夾；一般情況只需選影片、按「建立網頁」。
- 美化操作介面，顯示讀取進度、字幕摘要與就緒提示；完整參數保留在可展開的進階設定。
- 可自訂標題、作者、單位、簡介、封面、預設字幕與儲存位置，亦可手動增刪字幕。
- 支援載入既有網頁設定並另存新包；一般影片採單欄播放器，不需要章節索引。

## 安全與相容性

- 不修改原始影片／字幕、不覆寫既有輸出資料夾；延續符號連結與 Windows reparse point 防護。
- 新增 Windows／macOS 原生介面操作測試及成品匯出 smoke test，與既有安全回歸、播放器測試共同作為發布門檻。
- MP4 不重新編碼，實際播放取決於瀏覽器對影片編碼的支援。多語字幕為單軌切換，不是雙語並列。
- 取消或錯誤後可能保留非空暫存資料夾，程式會顯示位置；確認內容後再自行清理。
- README／網站既有截圖仍標示 v2.7.8，未以示意圖冒充新版截圖。
