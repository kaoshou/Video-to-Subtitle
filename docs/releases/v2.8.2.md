# v2.8.2 安裝後啟動與模型存取改善

## 修正與改善

- 改善 Windows 安裝完成後的自動啟動流程，透過桌面啟動程式；無法自動啟動時提供開始選單或桌面捷徑的操作指引。
- 模型因權限或系統限制暫時無法讀取時，不再誤判為快取損毀，也不會要求清除或重新下載已存在的模型。
- 模型管理以「檢查存取」提示無法讀取的狀態，主畫面、模型管理與轉錄流程使用一致的錯誤說明。
- 保留已下載模型、Windows 安全防護，以及原有 CPU、NVIDIA CUDA 與 Apple MLX 轉錄功能。

## 下載與使用

- Windows 安裝版：`VideoToSubtitle-Setup-v2.8.2.exe`
- Windows 免安裝版：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)
