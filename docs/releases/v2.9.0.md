# v2.9.0：字幕生成效能與校對流程升級

## 字幕生成效能

- CPU／CUDA 新增預設啟用的「批次加速（試用）」，將同一部影片的多段語音一起辨識。預設批次大小 4，可在進階設定改為 2／4／8／16／32，或關閉；已儲存的關閉偏好仍保留。
- 解碼後的音訊可重複利用，減少重試時的重複處理。記憶體不足會自動縮小批次，必要時回到一般轉錄，並沿用同次使用期間成功的較小上限。
- 批次結果會檢查辨識信心、重複內容與時間軸；異常時捨棄該次暫存並以一般流程重做，成功後才產生新的字幕檔，保留既有輸出。
- CPU 執行緒設定確實套用至模型核心。MLX 保留 Apple 原生加速及原有字幕功能，不套用 CPU／CUDA 的批次大小。

## 待校對提醒

- 新增 `!` 標記、待校對數量、「僅顯示待校對」篩選及所選字幕的原因提示，可搭配搜尋一起使用。
- 模型平均對數機率低於 -1.0 時提示「辨識信心偏低」，壓縮比大於 2.4 時提示疑似重複；另檢查相鄰重複文字、非法時間及時間重疊。這些是校對線索，不是正確率，也不會自動刪改字幕。
- 文字、時間、分割與合併後重新比對提醒；改善篩選狀態下合併與編輯內容保留。

## 進度與校對操作

- 顯示目前處理階段、階段耗時與總耗時，涵蓋模型準備、音訊處理、辨識、降級重試及儲存。
- 字幕編輯器的時間與操作工具列分列並自動換行，改善窄面板及高 DPI 下按鈕被截斷；保留影片播放控制所需空間。
- 新增獨立「儲存」、「儲存並關閉」、未儲存狀態及 Ctrl+S／macOS ⌘S。關閉前可選儲存、捨棄或返回編輯；寫入失敗時保留修改。

## 修正

- 改善 Windows 特定主控台編碼下，中文影音路徑影響轉錄啟動的問題。
- 改善取消、失敗與重試時的輸出保護，避免發布失敗嘗試的部分字幕或覆寫既有檔案。
