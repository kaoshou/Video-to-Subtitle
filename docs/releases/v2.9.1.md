# v2.9.1｜網頁閱讀與課程辨識改善

## 改善

- **一般 MP4 網頁播放器與 EverCam 一致**：共用同一份播放器版面與操作程式，只省略章節分頁，開頁即在右側提供逐字稿；播放控制、搜尋、跟隨播放、閱讀設定、逐字稿下載與鍵盤導覽一致。移除 MP4 額外的收合工具列，窄螢幕改在影片下方閱讀。
- **待處理清單的課程徽章**：辨識到 EverCam 或 OpenCam 時，在對應檔案列標示專案類型，方便確認匯入內容。

## 修正

- **MP4 命名資料夾的拖入判斷**：例如 `示範課程.ecmx.mp4` 會依實際目錄內容尋找影音，不再把資料夾當成影片；重複匯入不重複加入，掃描不跟隨子項目的符號連結。

## 下載

成品統一標示版本、平台與架構，Windows 安裝程式只保留一份：

- `VideoToSubtitle_v2.9.1_macOS_arm64.dmg`
- `VideoToSubtitle_v2.9.1_Windows_x64_Portable.zip`：解壓後執行內部 `VideoToSubtitle.exe`。
- `VideoToSubtitle_v2.9.1_Windows_x64_Setup.exe`

使用者不需預裝 Python；模型下載及既有設定沿用原本方式。
