# v2.7.11 字幕網頁匯出穩定性改善

## 新增與改善

- 改善 Windows 建立字幕網頁時的檔案占用錯誤，資源寫入並關閉後再發布完整資料夾。
- 保留原始影片、字幕與既有輸出，持續提供安全寫入、符號連結防護及暫存保留機制。
- 改善占用錯誤提示，詳細資訊加入程式版本、處理階段與資源名稱，方便排查問題。

## 下載與使用

- Windows：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)
