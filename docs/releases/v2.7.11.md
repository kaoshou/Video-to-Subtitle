# v2.7.11：改善一般影片字幕網頁匯出的 Windows 共享衝突

## 修正內容

- 移除未發布匯出包內 `content → index.html` 等多餘的逐檔改名；資源直接以不可覆寫方式建立，全部寫入、同步並關閉後才整包發布。
- 保留既有檔案／hardlink 保護、符號連結防護、整包排他發布及失敗暫存保留機制。原始影片與字幕不被覆寫；EverCam 與字幕編輯器的原子替換流程不受影響。
- 修正占用提示：不再直接認定是其他程式造成；詳細資訊新增程式版本，資源寫入失敗時附上階段與資源名稱。
- 新增 Windows 原生持續讀取 handle 測試、連續五次匯出與檔案釋放檢查，以及資源寫入失敗／安全防護回歸測試。

## 驗證與適用範圍

在 Windows 受控測試中，舊版可重現相同 `content → index.html` WinError 32，修正後通過；此測試不代表已辨識使用者機器上的實際占用來源，也不宣稱能忽略整包發布時的任意持續鎖定。發布仍須通過 Windows／macOS 整批測試、打包後網頁匯出檢查，以及 macOS MLX 完整性檢查。

- macOS：`VideoToSubtitle.dmg`
