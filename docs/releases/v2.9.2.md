# v2.9.2｜轉錄完成後，一鍵匯出字幕網頁

## 修正與改善

- **解決結果清單擋住網頁匯出視窗**：一般 MP4 轉錄完成後，按「匯出字幕網頁」即可直接處理，不再另外開啟設定或詢問視窗。
- **自動建立完整播放器資料夾**：在影片旁建立 `影片名稱-web`，內含 `index.html`、`media.mp4`、字幕及播放器資源。同名資料夾自動加流水號，不覆寫原有成果，也不修改原始影片與字幕。
- **原清單顯示進度與結果**：建立期間顯示進度，完成後可直接按「開啟網頁」；失敗原因顯示於原清單，修正後即可重試，避免重複點擊啟動多次匯出。
- **保留多語字幕與安全防護**：優先使用本次產生的字幕，同時加入可配對的其他語系；保留字幕驗證、安全寫入與路徑檢查。首頁的完整設定介面仍可自訂標題、輸出位置等參數。
