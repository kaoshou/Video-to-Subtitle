# v2.7.15 強制繁體字幕修正

## 更新內容

- 修正 Windows 安裝版及免安裝版的 OpenCC 相依 DLL 收錄位置。保留元件所需的 `opencc.libs` 目錄，避免 DLL 被收錄到其他套件目錄而使繁體轉換元件無法載入。
- 勾選「強制繁體中文」時，先確認轉換元件可用，再載入語音模型。若元件不可用，會停止並顯示錯誤，不再默默略過繁體轉換；轉換途中故障也會停止批次處理。
- 正常啟用時，任務日誌會標明「強制繁體中文：已啟用 OpenCC」。繁體轉換在辨識後處理，不依賴前導提示是否能讓模型直接輸出繁體。
- 保留未勾選強制繁體、翻譯成英文及既有字幕編輯／網頁播放器的行為。不新增語音模型或使用者操作步驟。
- 增加成品的繁體字幕驗證與無主控台診斷報告；中文報告使用 UTF-8，測試終端輸出相容 Windows 舊編碼。

## 使用提醒

更新前請關閉舊程式。Windows 可執行新版安裝包更新，或改用新版免安裝 EXE；不需另外安裝 Python 或 OpenCC，也不需修改前導提示。設定、語音模型快取及影音檔案保留。

繁體轉換是字形與詞彙處理，不會修正同音字或所有專有名詞。字幕仍需人工校對。「翻譯為英文」模式維持不套用中文轉換。

## 驗證範圍

發布門檻包含 Windows／macOS 完整原生介面與檔案安全回歸、播放器及網站測試，以及兩平台成品的字幕網頁匯出與繁體字幕轉換。繁體成品檢查使用真實 OpenCC 字典及輸出流程，涵蓋 SRT、VTT、TXT、TSV、JSON 與兩種前導提示。

Windows 安裝版及免安裝版均驗證獨立轉換；安裝版另驗證暫時移除 DLL 目錄後的明確拒絕、還原後再次轉換，以及真實安裝、GUI 啟動、重裝與解除安裝。macOS 另驗證隔離主機環境的 MLX Metal 計算。

成品的合成字幕檢查不下載語音模型。本機另以 medium 模型完成約 4 分 50 秒影片的真實 CPU 轉錄；修正版 73 段字幕均完成繁體轉換，與未轉換對照的編號及時間軸一致。這不是所有 Windows／macOS 硬體或 GPU 模型推論的認證，也不代表辨識內容免於校對。
