# v2.7.15 強制繁體字幕修正

## 新增與改善

- 修正 Windows 安裝版及免安裝版的繁體轉換元件封裝，改善勾選「強制繁體中文」後仍出現簡體字的問題。
- 繁體轉換在語音辨識後統一處理，適用 SRT、VTT、TXT、TSV 與 JSON，不需調整前導提示。
- 啟用強制繁體時先檢查元件，並在任務日誌顯示啟用狀態；元件異常時提供明確錯誤提示。
- 更新時保留使用者設定、模型快取及影音檔案；英文翻譯模式維持原有流程。

## 下載與使用

- Windows 安裝版：`VideoToSubtitle-Setup-v2.7.15.exe`
- Windows 免安裝版：`VideoToSubtitle.exe`
- macOS：`VideoToSubtitle.dmg`
- [完整使用手冊（繁體中文）](https://kaoshou.github.io/Video-to-Subtitle/guide/)
