# v2.8.3：網頁播放器鍵盤操作與分組說明

## 新增

- 一般 MP4 與 EverCam 網頁播放器提供播放器、章節、逐字稿與操作說明的定位快捷鍵；鍵盤巡覽時才顯示跳轉連結。
- 操作說明整理為四個可獨立展開的小節，完整介紹播放、字幕、速度、章節、搜尋與閱讀設定。

## 改善

- 改善鍵盤播放控制、選單開啟與焦點返回；搜尋欄、滑桿及設定保留原有鍵盤操作。
- 播放後中央播放按鈕退出鍵盤巡覽，焦點移至可見控制項；使用鍵盤時保留控制列，滑鼠播放時維持自動隱藏。
- 操作說明入口維持小巧外觀，增加可點擊範圍，保留原有配色與版面。
- 改善手機版清除逐字稿搜尋時的頁面跳動，跟隨播放維持在逐字稿清單內捲動。
- 官網統一使用「版本更新內容」連結文字；README 精簡歷史子版本摘要，集中呈現最新功能。

## 下載

- Windows 免安裝版：`VideoToSubtitle.exe`
- Windows 安裝版：`VideoToSubtitle-Setup-v2.8.3.exe`
- macOS：`VideoToSubtitle.dmg`

更新播放器功能請重新匯出網頁；既有輸出檔案不會自動更新。
