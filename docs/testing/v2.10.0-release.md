## 發布前發現並修正

- PyInstaller console 入口未將專案放入 Python 搜尋路徑，使第三方授權收集器匯入失敗。兩份 spec 使用 PyInstaller 提供的 SPECPATH；隔離 Python 重現先失敗，再驗證修正成功。封裝邊界測試也提供真實建置環境的 SPECPATH。
- Windows 合成 Ctrl+S 事件先聚焦編輯文字區；安全匯出測試使用 30 秒有界輪詢並附工作診斷，不更動產品安全回退或刪除檢查。
- 新 MCP 手冊跨頁錨點先解碼再映射；舊「熱詞」測試用語更新為「專有名詞」。截圖產物即使網站檢查失敗仍保留，以利定位。
- 第一輪正式 Windows 安全回歸攔下測試資料的 CP1252 編碼錯誤、路徑分隔符假設，以及 GUI 合成辨識器與新版預設模型不一致。改為明確 UTF-8／Path.parts，GUI 測試明確選 medium 並阻擋意外載入模型；該原生案例與本機 608 項／網站 28 項重跑通過。產品模組與安全檢查不因這些測試修正改動。
- Windows 成品在第一輪正式流程已通過安裝、重裝、解除安裝、獨立 MCP／後端及繁體中文元件煙霧。發布仍等待修正測試後的正式流程通過，不以此取代安全回歸。
- 修正測試後的 Windows 608 項回歸已通過（19 項依平台略過）。macOS 安全工作因 GitHub ARM 容量不足、未獲執行器而取消，註記為「The job was not acquired by Runner of type hosted even after multiple attempts」。通用 macOS 檔案／GUI 回歸改用官方 macos-15-intel 執行器，保留所有測試；正式 App、MLX／Metal 與封裝後端煙霧仍在 macos-latest ARM 建置中執行，不以 Intel 結果代替 ARM 成品驗證。
