## 發布前發現並修正

- PyInstaller console 入口未將專案放入 Python 搜尋路徑，使第三方授權收集器匯入失敗。兩份 spec 使用 PyInstaller 提供的 SPECPATH；隔離 Python 重現先失敗，再驗證修正成功。封裝邊界測試也提供真實建置環境的 SPECPATH。
- Windows 合成 Ctrl+S 事件先聚焦編輯文字區；安全匯出測試使用 30 秒有界輪詢並附工作診斷，不更動產品安全回退或刪除檢查。
- 新 MCP 手冊跨頁錨點先解碼再映射；舊「熱詞」測試用語更新為「專有名詞」。截圖產物即使網站檢查失敗仍保留，以利定位。

## 雲端正式發布閘門

main 的跨平台工作流程必須同時完成 Windows／macOS 封裝、安全回歸與瀏覽器檢查，才會建立公開 Release。Windows 包含安裝、重裝、安裝後啟動及移除煙霧；模型快取與使用者素材不作測試輸入。

正式發布僅含三個平台成品，版本為 2.10.0。測試細節放在此紀錄與 Actions，公開 Release 說明僅列功能變更。
