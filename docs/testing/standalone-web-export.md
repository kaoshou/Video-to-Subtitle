# 一般影片網頁匯出：v2.7.9 驗證紀錄

## 2026-10-13 逐字稿搜尋驗證（v2.7.13）

- EverCam 與一般 MP4＋字幕共用播放器。新增逐字稿、語言選擇、大小寫不敏感的字串搜尋、關鍵字標示及點選時間跳轉。EverCam 章節與逐字稿以分頁共用右側欄，預設章節；一般 MP4 預設收合側欄，展開時只有逐字稿分頁。
- Node 播放器 11 項、網站 18 項測試通過。包含兩種模式、字幕關閉後搜尋、字幕語言同步、特殊符號／HTML 作為純文字、長逐字稿分批顯示及搜尋未顯示的段落；新增預設收合、按鈕展開／收合、搜尋焦點、條件保留、分頁鍵盤操作與切換不影響播放的測試。
- 獨立 Python 3.13 測試環境（PyAV 19.0.1、Pillow 12.3.0）：107 項測試完成，85 通過、22 項平台／原生 GUI 測試略過；未將略過項目計為通過。
- 真實合成 MP4、兩軌字幕：以一般匯出器建立網頁包，也以 EverCam 部署流程建立課程頁。Codex 內建瀏覽器實際搜尋「索引」得到兩段，點選三秒結果後影片時間為約 3.4 秒且正在播放；EverCam 章節亦跟隨跳轉。
- 桌面與 390×844 手機視窗已視覺檢查，搜尋欄、清除按鈕與結果均可操作。EverCam 預設顯示章節分頁；一般 MP4 的入口保留於播放器下緣工具列右側，可展開與收合逐字稿側欄。兩種模式手機頁面寬度與捲動寬度均為 390px，閱讀面板置於影片下方，沒有水平溢出。測試 HTTP 伺服器提供影片 byte-range 請求，確保瀏覽器可跳轉；無 byte-range 的簡易伺服器不作為影片跳轉驗收環境。
- 直接以 `file://` 開啟的實際瀏覽器驗證受工具 URL 政策限制，未執行。搜尋使用包內已載入的字幕資料，不另外請求字幕檔或外部服務。
- 兩種播放器的頂部橫幅恢復原本淺色藍綠樣式，移除新增的分類文字與深色裝飾，縮減留白及桌面標題字級；單行 EverCam 範例實測高度約 80px。一般 MP4 實際輸出包以長中文標題、作者及單位檢查手機視窗，沒有水平溢出。
