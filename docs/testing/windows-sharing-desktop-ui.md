# Windows 檔案占用與原生介面改善：驗證紀錄

日期：2026-10-08。基準：v2.7.9（`2527d1e`）。本次在 `codex/windows-sharing-ui` 測試分支實作，未更新 main、版本號或公開 Release。

## 修正與回歸範圍

- Windows 發布暫存檔時，僅對 WinError 32／33 有限次重試；每個操作最多等待 4.55 秒。每次仍檢查目的路徑，保留原有原子寫入、不可覆寫及符號連結防護。
- 暫存清理失敗不再掩蓋原始錯誤；一般網頁視窗顯示簡短說明，完整錯誤／保留位置可展開並選取複製。
- EverCam 標題、描述、工具列分行；課程長路徑換行，課程操作與底部操作區不再和文字互相擠壓。
- 兩個轉換視窗支援影片拖入；一般 MP4 沿用同名／語系字幕自動配對，EverCam 影片解析所屬課程。拖放使用 Tcl 檔案清單解析，保留中文、空白與大括號。
- 共用原生配色及繁體中文字體，保留深淺色模式。主視窗設定可捲動，進階參數仍保留。

## 驗證界線

- 不能僅從使用者照片判定是哪個程式占用檔案；不把防毒程式列為已證實原因，也不建議關閉防護。
- 拖放測試是原生元件註冊、Tcl 事件傳遞及檔案處理測試，不等於人工從 Windows Explorer／macOS Finder 拖曳滑鼠的驗收。
- CTk 縮放幾何測試不等於所有實體螢幕、系統縮放、多螢幕切換或輔助功能設定已測完。
- 本機 Python 3.12／Tk 9／CustomTkinter 6 整批原生測試通過一次，但重跑仍在反覆銷毀、重建 Tk interpreter 後出現原生崩潰。測試已加入工作執行緒收尾與主執行緒回收，但這**沒有證實解決偶發崩潰**。單一主視窗的 5 次實際匯出生命週期通過；這與多 interpreter 測試及正式打包環境的證據分開列示，不推論所有 Tk 9 情境皆安全。
- 未重做真實畫面截圖，不用示意圖代替原生畫面驗收。未重新跑模型下載／整段語音辨識與完整瀏覽器播放矩陣。
